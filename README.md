# Local RAG System with Ollama

A local Retrieval-Augmented Generation (RAG) system using:

- Ollama
- ChromaDB
- Python

## Features

- Local LLM inference
- Document ingestion (PDF)
- Semantic search
- Question answering over documents

## Tech Stack

- Ollama
- Chroma Vector DB
- Python
- Requests

## Usage

Run:

python app/full_rag.py
